Architecture · Illustrate

Three runs at once, one tree each

Dispatch is non-blocking, so fanning out is just repeated start calls. The constraint is not concurrency — it is that a write-capable run needs a tree of its own.

Measured on three concurrent Codex runs: dispatched inside one second, 130 s of wall clock for all three. Sharing a directory does not corrupt the work — it corrupts the attribution, because the tripwire watches the tree, not the author.
