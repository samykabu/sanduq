# Standalone projects

Applies without `.specify/workflow.yml`.

- The native command is `/speckit-scope-run`; `/speckit-scope` is the short entry point. Both run
  this skill, which provides the analyst role without a vendor-specific agent schema. Source and
  reinstall instructions are in `.specify/extensions/scope/README.md`.
- This skill is the authority. Do not invoke Specify: leave the enriched Specify prompt of each
  approved executable issue ready for the user's next step.
