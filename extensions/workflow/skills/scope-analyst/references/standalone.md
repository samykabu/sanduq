Applies without `.specify/workflow.yml`.

- The command is `/speckit-workflow-scope-run`. It runs this skill, which provides the analyst role
  without a vendor-specific agent schema. Source and
  reinstall instructions are in `.specify/extensions/workflow/README.md`.
- This skill is the authority. Do not invoke Specify: leave the enriched Specify prompt of each
  approved executable issue ready for the user's next step.
