# Stage reference: qa_document

## Required work and evidence

Generate and verify tester evidence only when QA is selected. Never claim human QA happened
because a walkthrough exists.

Build the walkthrough from the reviewed scenario/result index and link its
[canonical evidence snapshot](evidence-capture.md#reusing-a-canonical-fact-source). Keep
tester steps, required coverage, screenshots, redaction and freshness; do not copy raw inventories.
