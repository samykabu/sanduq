# Scope gate preset

Adds the Scope entry contract and unattended Clarify workflow using `strategy: prepend`.
Core Specify and Clarify are composed from the installed version, not copied into this preset. Install through
the workflow package installer through Spec Kit public preset commands and repeat after updating Spec Kit.
The optional sibling `scope-brainstorm` preset applies the same workflow to installed
Superspec Brainstorm without preventing Clarify fallback when Superspec is absent.
