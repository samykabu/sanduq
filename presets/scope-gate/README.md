# Scope gate preset

Adds the Scope entry contract to Specify (`strategy: prepend`; core Specify is composed from the
installed version) and replaces Clarify (`strategy: replace`) with a short pointer to the shared
GitHub clarification skill, which holds the coverage categories and answer rules. Install through
the workflow package installer or the Spec Kit public preset commands, and repeat after updating
Spec Kit or this preset. The optional sibling `scope-brainstorm` preset applies the same workflow
to Superspec Brainstorm.
