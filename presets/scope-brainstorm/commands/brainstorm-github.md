# SuperSpec Brainstorm

Input: $ARGUMENTS

This command replaces the upstream interactive Brainstorm. Execute
`.specify/extensions/scope/skills/github-clarification/SKILL.md` with `engine: brainstorm`, using
the explicit issue number or the bound feature. It supersedes SuperSpec's and Superpowers'
one-at-a-time questioning, quotas and chat approvals; a brainstorming skill must not bring them
back. Never ask brainstorm questions in this chat. When it returns, STOP.
