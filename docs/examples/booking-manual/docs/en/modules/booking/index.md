# Request a refund

## Before you start

Sign in as an operator with access to the booking. Confirm the reservation and the refundable amount before submitting a request.

## Submit the request

1. Open **Bookings** and select the reservation.
2. Choose **Request refund**.
3. Enter a reason and confirm the amount.
4. Choose **Submit** once.

Expected result: the refund appears as **Pending approval**. Submission records a request; payment settlement follows approval.

## If access is refused

Ask an administrator to review your booking permissions. Do not retry under another user's account.
