# Manage operator access

## Assign access

1. Open **Operations**, then **Operators**.
2. Select the operator and review their current role.
3. Grant only the permissions needed for their booking or refund work.
4. Save, then verify the permission in the operator record.

## Inspect the history

Open the booking's refund history and compare the request, decision, provider response, and final recorded state. Keep the original decision visible when recovery is required.
