# Licenses

Check the license of each package you install. Most Sanduq extensions are source available for
noncommercial use. Scope and its presets, and every portable skill, are MIT.

## Can I use this?

| Use | Allowed |
| --- | --- |
| Portable skills from sanduq-skills, any purpose | Yes (MIT) |
| Scope, `scope-gate`, `scope-brainstorm`, any purpose | Yes (MIT) |
| Other extensions and the `workflow` preset, noncommercial | Yes (PolyForm Noncommercial 1.0.0) |
| Other extensions and the `workflow` preset, commercial | Needs a separate written license from [Samy K. Abushanab](https://github.com/samykabu) |

PolyForm Noncommercial is not an OSI-approved open-source license.

## Vendored skills

Illustrate, User Manual and Workflow ship copies of portable skills, pinned in
[`vendor.lock.json`](../../vendor.lock.json). Those skills are MIT in sanduq-skills. If you need a
skill under MIT terms, install it from sanduq-skills rather than taking it out of an extension package.
