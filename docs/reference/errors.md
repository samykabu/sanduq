# Error codes

Every refusal from `workflow.py`, `install.py` and `upgrade.py` prints `{"ok": false, "error": "<CODE>: <detail>"}`.
For the codes below the JSON also carries `explain` (what happened and why it is refused) and `next` (the command
to run). `workflow.py doctor` lists the same codes in its `errors` and `warnings` arrays.

```text
$ python .specify/extensions/workflow/scripts/workflow.py status --feature specs/412-refund-approval
{"ok": false, "error": "WORKFLOW_START_REQUIRED", "explain": "The feature has no checkpoint. Every stage command needs the binding start writes.", "next": "python .specify/extensions/workflow/scripts/workflow.py start --feature specs/412-refund-approval --issue <owner/repo#N>"}
```

A code that is not listed prints only `error`; its message still names the condition. For a stale receipt,
`gate_explain.py` gives the exact amend or redo recipe. See [troubleshooting](../start/troubleshooting.md) for
symptoms that are not one code.
